## 🎯 Deliverables

### 1. Makalah (PDF)
Makalah harus mencakup:
- ✅ **Manajemen Data:** Proses pengumpulan, pembersihan, transformasi, dan persiapan data
- ✅ **Asosiasi Data:** Analisis hubungan antar variabel (association rules, market basket analysis)
- ✅ **Korelasi Data:** Analisis korelasi antar fitur numerik
- ✅ **Analisis Regresi:** Model prediksi menggunakan regresi (linear/multiple regression)
- ✅ **Klasifikasi Data:** Model klasifikasi dengan algoritma machine learning
- ✅ **Clustering Data:** Segmentasi data menggunakan clustering (K-Means, Hierarchical, dll)
- ✅ **Big Data dan Perkembangannya:** Pembahasan tentang big data, tools, dan strategi scaling

### 2. Project Code
- Dataset lengkap (minimal 1000-1500 rows)
- Jupyter Notebook / Python scripts
- Visualisasi data
- Model machine learning yang terlatih
- Dokumentasi lengkap (README, comments)
